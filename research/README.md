# Research and simulation

This tree holds investigations and offline evaluation tools, separately from
the services that operate Options View.

| Home | Purpose |
|---|---|
| [studies](studies/brian-r2-20261024/README.md) | Preserved empirical studies and their evidence; currently the October price/variance study |
| [snapshot_analysis](snapshot_analysis/README.md) | MOO-171 archive audit, concentration/activity measurements and frozen results |
| [synthetic_days](synthetic_days/README.md) | Historical resampling and strategy replay against synthetic sessions |

The studies and snapshot-analysis trees were moved byte-for-byte. Their dated
paths, issue names, reports and source hashes remain historical evidence; do not
rewrite them to make a current directory listing look tidy. Run each tool from
its own directory as its guide describes. Synthetic replay finds Crassus at the
repository root. These tools do not establish current production data freshness.
